# Spoti-Hud (Fabric, Minecraft 1.21.11)
1. Spotify Developer Dashboard'da app oluştur, Redirect URI: http://127.0.0.1:8888/
2. Oyunu aç -> tarayıcıda http://127.0.0.1:8888/ aç (PC veya telefon, oyunla aynı cihaz) -> Client ID gir -> giriş yap.
3. Tarayıcı sekmesi açık kalmalı (arka planda). Spotify'da bir şey çal.
Tuşlar (değiştirilebilir): , = önceki  / = durdur-başlat  . = sonraki
Kontrol için Spotify Premium gerekir.
